**Headline finding (important):** portal credentials are **systemic, not a 2-file anomaly**.
The master response/report template embeds a header block (`Application Site` URL →
`User Name` → `Password` → `Google Drive Folder`) in nearly every funder response/report docx.
**60 files carry a filled username or password in that block (52 with a real password value,
58 with a filled staff email, union 60),** incl. ~30 distinct passwords and one shared
default password reused across ~19 files. The two seed files
(`8_17_2026 - Philadelphia Foundation.docx`, `7_31_25 William Penn Report.docx`) are just the
tip of this iceberg. All 60 are **REDACT** with a single mechanical target: strip the portal
login block. No SSN digit sequences exist anywhere in extractable text; one signed W-9
(`fw9.pdf`) is the only true tax form.

## 1. Method + re-run commands

Extraction artifacts are kept in `/tmp/opencode/scan/{docx,pdf,xlsx}/` with the file's relative
path under `data/Grants/` (each source file → `<relpath>.txt`). Re-run:

```bash
# Setup
mkdir -p /tmp/opencode/scan/{docx,pdf,xlsx}

# 1) All 528 .docx (first 4000 chars each) — the primary credential carrier
find data/Grants -type f -iname '*.docx' -print0 \
  | xargs -0 -P 8 -I{} python3 /tmp/opencode/docx2txt.py "{}" 4000 \
    > /tmp/opencode/scan/docx/<relpath>.txt

# 2) Targeted .pdf subset (first 4 pages, 20 KB cap): Reporting / Meeting* / Finances /
#    Attachments / Responses / DAF / Grant Application paths
find data/Grants -type f -iname '*.pdf' -print0 \
  | grep -zE '/(Reporting|Meeting|Finances|Attachments|Responses|DAF|Grant Application)/' \
  | xargs -0 -P 8 -I{} pdftotext -l 4 "{}" - \
    > /tmp/opencode/scan/pdf/<relpath>.txt

# 3) All 165 .xlsx (8 rows/sheet)
find data/Grants -type f -iname '*.xlsx' -print0 \
  | xargs -0 -P 8 -I{} python3 /tmp/opencode/xlsx2txt.py "{}" 8 \
    > /tmp/opencode/scan/xlsx/<relpath>.txt
```

Detection (bash, run inside `/tmp/opencode/scan`):

```bash
# portal credentials — then inspect the line AFTER 'User Name' / 'Password' for a filled value
grep -rIlE 'User ?[Nn]ame|Pass ?[Ww]ord|Passcode|Login' docx pdf xlsx

# SSN digits (none found) / tax keywords
grep -rIlE '[0-9]{3}-[0-9]{2}-[0-9]{4}|Social ?[Ss]ecurity|W-?9|EIN|Tax ?ID|SSN' docx pdf xlsx

# salary / donor / student / bio / LOS
grep -rIlE 'hourly|salary|compensation|pay ?rate|wage' docx pdf xlsx
grep -rIlE 'donor-?advised|DAF|gift acknowledg|donor list' docx pdf xlsx
grep -rIlE 'empathy interview|student interview|transcript|consent form' docx pdf xlsx
grep -rIlE 'biograph|Leadership Bios|Board Bios' docx pdf xlsx
grep -rIlE 'letter ?s? of support' docx pdf xlsx
```

Media/photo classes (not text-extractable) are enumerated by filename:

```bash
find data/Grants -type f \( -iname '*.mp4' -o -iname '*.m4a' -o -iname '*.vtt' \
  -o -iname '*.heic' -o -iname '*.jpg' \) | grep -iE 'interview|students|full story|q[0-9]\.mp4'
```

**Coverage note:** 528/528 docx and 165/165 xlsx extracted. 208 targeted PDFs extracted;
~212 PDFs outside the targeted path segments (990s, RFPs, agreements, marketing, site-visit
decks) were not text-scanned — media/image PDFs are excluded regardless, and 990s are
public-reference only (§2). No SSN digit patterns found in any extractable text.
