## 2. Method

For each target, opened the source docx with `zipfile`, parsed `word/document.xml`
(`xml.etree.ElementTree`), then:

1. **Removed whole table rows** whose first-cell text exactly equals one of
   `Application Site | User Name | Password | Google Drive Folder | Passcode`
   (the portal credential header block — label cell + value cell in one row, so the
   credential value leaves with its row). Matches at any position (handles the one file,
   Philadelphia Foundation 2026, that carries a duplicated block — 8 rows).
2. **Removed the standalone passcode paragraph** in `Launch & Learn_.docx`
   (`(Passcode: …)` paragraph; this file's access value lives in a paragraph, not a row).
3. **Bio docs (2f), keeping name/title/role:**
   - `Current and Past/Allentown SD RFP/11.5.24 ASD AI High School.docx` — the "bio section"
     is actually a third-party references block (name / phone / email of partner-org
     representatives) inside the GRANT OVERVIEW table cell. Removed the "references" prompt
     and all following paragraphs in that cell (prompt, 3 reference contacts, phone/email lines).
     Kept the personnel list (name + role only) and all program content.
   - `Prospects and Proposals/1954 Project/12_4_25 1954 Project Luminary Pre-Application.docx` —
     removed the leader personal-history bio (title paragraph + single-cell narrative table);
     replaced with the minimal name/title line
     `Dannyelle Austin — Inaugural Executive Director of Launchpad`.
4. Re-wrote each docx preserving every other zip entry byte-for-byte; only `word/document.xml`
   is replaced.

No file under `data/` (or anywhere in the repo) was modified, created, or deleted.
